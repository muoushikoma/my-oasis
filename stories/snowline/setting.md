# 雪线 · 世界观

北方，一片没有名字的寒带荒野：针叶林、冻住的湖、废弃的铁路和小镇，远处是山和海岸。
某件事发生之后（每一局都不一样：可能是一场无声的大雪、一次极光后的全面停电、一列没有到站的火车……），
电话、收音机、汽车都不再可靠，人们要么离开了，要么没能离开。

主角是一个普通人，独自留在这片雪原上。没有超能力，没有怪物，没有僵尸。
敌人是寒冷、饥饿、黑夜、狼，还有自己的判断失误。雪原上还零星活着几个人，他们和你一样在挣扎，可能帮你，也可能和你抢最后一罐食物。

基调：
- 安静、克制、带一点孤独的温度。像在雪地里捡到的一张旧便条。
- 不渲染血腥。受伤、死亡点到为止。
- 世界里的人留下的痕迹（笔记、照片、没吃完的罐头、熄灭的炉子）比人本身更多。
- 每局只有两三个其他幸存者，各有各的处境和秘密；绝不出现超自然现象。

画面：简约的黑白手绘风，俯视角缩略地图，主角是地图上的一个小人。
