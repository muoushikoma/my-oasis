# 无尽之路 / The Endless Road

一条没有尽头的路，从左往右一直走。每走一里吃掉 1 份口粮，并遇到一个由 AI 现场写成的新事件。管好资源、强化装备、收集遗物，看你能走多远。**这个故事需要接入 AI。**

A road with no end, walked left to right. Every mile costs a ration and brings a new event. Manage supplies, upgrade your gear, collect relics — see how far you can go.

## 一、事件框架

每一里的流程：

1. **引擎掷骰**：事件类别（按地区加权）和强度（弱 / 普通 / 强 / 精英；每 25 里一个守关者）。
2. **AI 写事件卡**：标题、2~3 句描述、2~3 个选项，以及画面模块（见第四节）。
3. **玩家选择**：选项列在卡片上，每个都写明了动作、难度、成功收获和失败风险的**确切数值**。
4. **规则结算**：掷骰、发放收获或承担风险。

| 类别 | 内容 | 能用的选项动作 |
|---|---|---|
| ⚔ 战斗 combat | 一个敌人 | 动手（必有）、检定（如偷偷绕过）、付出（如贿赂） |
| 💬 遭遇 encounter | 会说话的人或生物 | 检定、付出、赌运、动手、接委托 |
| 🔍 发现 discovery | 废墟、宝箱、遗物 | 检定、赌运、付出 |
| ⚠ 险境 hazard | 断桥、风暴、落石 | 检定、付出（离开 = 绕路，多耗口粮） |
| ✨ 秘境 mystic | 祭坛、精灵、诅咒之物 | 检定、付出、赌运 |
| ⚖ 抉择 dilemma | 两难的道德选择 | 付出、检定、接委托、动手 |
| 📜 委托 quest | 之前接下的委托的结局 | 检定、付出、动手、赌运（收获更大，可给遗物） |
| 🛒 交易 trade | 行商（带铁砧） | 打开商店：补给、卖铁料、强化 |
| 🔥 休憩 rest | 安全的歇脚地 | 免费扎营，完全恢复 |

**选项动作**
- **检定**：属性 + 难度（易 / 中 / 难 → DC），d20 + 调整值 + 熟练加值。难度越高收获越大。
- **付出**：花金币、口粮、药水、生命、铁料或魔晶，换一份确定的大收获。
- **赌运**：五五开，收获大、风险也大。
- **动手**：进入战斗（攻击 / 喝药水 / 逃跑）。
- **接委托**：4~8 里后会遇到委托的结局事件。同时只能接一个。
- 每张卡都可以**离开**，有时也可以先**喝药水**再做决定。

**收获菜单**：金币、口粮、药水、恢复生命、铁料、魔晶、经验、祝福、遗物（只有困难检定和委托结局才给）、侦察。
**风险菜单**：受伤、丢金币、丢口粮、诅咒、中毒、被袭击（转入战斗，敌人先手）、迷路、疲惫。

数值由规则按威胁等级和难度计算（`scripts/road.js` 里的 `rewardAmount` / `riskAmount` / `costAmount`），AI 只能从菜单里挑类型。

**状态效果**：祝福（d20 +2）、诅咒（d20 -2）、中毒（每里 -1d4，喝药水可解）、疲惫（AC -2，扎营解除）、侦察（接下来更容易避开战斗）。

## 二、资源与强化

| 资源 | 用途 | 来源 |
|---|---|---|
| 口粮 | 每里 1 份，吃完会挨饿掉血；扎营也要 1 份 | 行商、战胜野兽、事件 |
| 治疗药水 | 回血、解毒 | 行商、事件、守关者 |
| 金币 | 买补给、强化、付出代价 | 战斗、事件 |
| 铁料 | 强化材料；也可以卖钱 | 战斗、发现、事件 |
| 魔晶 | 高级强化材料 | 秘境、守关者、高收获事件 |

**携带上限**：口粮 8 + 4×背包等级，药水 3 + 背包等级；装不下的会丢掉。

**强化**（在交易事件里，用金币 + 铁料，高级还要魔晶）：

| 强化 | 最高 | 效果 |
|---|---|---|
| 武器 | +5 | 命中与伤害 +1 / 级 |
| 护甲 | +5 | AC +1 / 级 |
| 背包 | Lv3 | 口粮上限 +4、药水上限 +1 / 级 |
| 营具 | Lv3 | 扎营回血 50% → 65% → 80% → 100%，夜袭 20% → 14% → 8% → 4% |

**遗物**（最多 3 件，满了会化成 2 魔晶）：幸运符（d20 +1）、吸血之刃（命中回 2 血）、旅人靴（25% 不耗口粮）、守护护符（AC +1）、猎人号角（击败敌人金币 ×1.5）、炼金瓶（药水 ×1.5）、星图（预知下一里的事件类别）、不灭余烬（致命伤时留 1 血，用掉）。

## 三、角色与战斗（简化 D&D 5e）

- 开局掷属性（4d6 去掉最低），生命 = 14 + 体质调整值，长剑 1d10 + 力量/敏捷调整值。
- 攻击和检定：d20 + 调整值 + 熟练加值，对抗 AC / DC；20 自动成功、伤害骰翻倍，1 自动失败。
- 升级：生命 +1d10 + 体质；4、8、12…级攻击属性 +2；5 级起每回合攻击两次。
- 扎营：每里一次，消耗 1 份口粮；地区每 10 里变换；威胁随里程增长，后期越来越快。
- 最远纪录保存在本机，不随读档回滚。

## 四、AI 与画面模块

AI 只有 0 级权限：不能改任何数值。它写的每个字段都会被规则校验（动作是否适用于这个类别、收获是否允许、精灵是否在白名单里），不合规的会被丢掉或换成默认值；如果一个可用的选项都没剩下，规则会补一组通用选项。AI 超过 25 秒没有回应时，事件卡会提示检查 AI 设置，并显示“重试”按钮。

画面是 256×144 的像素画布（`scripts/scene.js`），每一帧由模块叠出来：

| 层 | 模块 | 谁来选 |
|---|---|---|
| 背景 | 6 个地区 × 4 层（天空、远景、中景、地面与路），视差卷动 | 规则 |
| 主体 | 敌人 `wolf` `spider` `bandit` `skeleton` `troll` `drake` `ooze` `wisp` `warden`；场景 `chasm` `rocks` `thorns` `chest` `cart` `shrine` `campfire` `stranger` | AI（按类别限定白名单） |
| 染色 | `none` `red` `green` `blue` `gold` `shadow` `pale` `purple` | AI |
| 时间 / 天气 | `day` `dusk` `night` / `clear` `rain` `snow` `fog` `embers` `fireflies` `leaves` | AI（有默认值） |
| 主角 | 站立、走路 4 帧、攻击 | 规则 |

**提前生成**：AI 始终比玩家多准备一里。开局就掷出第 1 里的事件并在后台请求 AI（`trigger: script` + `api.ai.request`，不阻塞游戏），之后每走一里就接手已经写好的卡片、同时开始准备下一里。玩家处理眼前的事时，下一里已经在写了，走过去时卡片直接出现；事件面板上会显示“✓ 下一里已经备好”。如果还没写好，就先显示“前方有动静”，写好后自动出现；请求失败或读档后丢失，会自动重新请求。下一里的地区、守关者、委托回访在掷骰时就已确定，所以提前写的内容和实际情况一致。

**界面**（自定义网格布局，三个面板是故事自带的**自定义组件** `ui/panel.html`，用 `config.view` 区分）：

| 位置 | 内容 |
|---|---|
| 左上 | 像素画布 |
| 左下 | 日志（每张事件卡的选项也会写进日志） |
| 右栏 · 行动栏 | 生命条、资源、继续前进 / 攻击 / 药水 / 扎营 / 逃跑（按当前阶段自动变灰） |
| 右栏 · 事件面板 | 事件卡或商店；赶路时显示前路和“下一里是否备好” |
| 右栏 · 信息面板 | 角色、行囊与强化、遗物与状态、旅程，每组可以折叠 |
| 右栏底部 | 远方（AI 生图的位置）、备用按钮 |

规则把要显示的内容写进玩家可见的状态（`ui_card` 等），面板只负责显示；点选项调用 `choose` / `trade` 动作，行动按钮调用 `walk` / `camp` / `potion` / `attack` / `flee`。玩家在设置里关掉自定义组件时，可以用右栏底部的备用按钮按编号选择。

**平台**：目前只声明电脑端。当前客户端在手机上会把所有区域压进一屏高，右栏内容多时会和日志重叠；客户端修好后可以加回 `mobile`。

素材的源文件和加新精灵的方法见仓库 `tools/art/endless-road/`。

## 文件

```
story.yaml          主文件（状态、动作、AI 接入点、界面）
scripts/road.js     规则：事件框架、选项结算、资源与强化、遗物、状态效果、战斗、事件卡界面
scripts/scene.js    画面：模块合成、动画、天气、时间
ui/panel.*          三个面板（自定义组件）：行动栏、事件 / 商店、信息
assets/bg/          背景分层；assets/sprites/ 精灵；assets/cover.png 封面；assets/vista.png 生图的替代图
```
