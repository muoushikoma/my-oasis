# 无尽之路 / The Endless Road

一条没有尽头的路，从左往右一直走。每走一里吃掉 1 份口粮，并遇到一个由 AI 现场写成的新事件。管好资源、强化装备、收集遗物，看你能走多远。**这个故事需要接入 AI。**

A road with no end, walked left to right. Every mile costs a ration and brings a new event. Manage supplies, upgrade your gear, collect relics — see how far you can go.

**玩法核心**：战斗是回合制的读招——敌人每回合预告下一步；每个职业有一种资源和 3 个技能；升级三选一天赋；每 5 里一个岔路口；疲劳和口粮逼着你在“赶路”和“扎营”之间取舍。AI 不只是写描述：每个选项的成败旁白、敌人的特性和台词、贯穿全程的旅途主线都是它写的（界面里用 ✦ 标出）。

## 一、事件框架

每一里的流程：

1. **引擎掷骰**：事件类别（按地区加权）和强度（弱 / 普通 / 强 / 精英；每 25 里一个守关者）。
2. **AI 写事件卡**：标题、2~3 句描述、2~3 个选项，以及画面模块（见第四节）。
3. **玩家选择**：选项列在卡片上，每个都写明了动作、难度、成功收获和失败风险的**确切数值**。
4. **规则结算**：掷骰、发放收获或承担风险。

| 类别 | 内容 | 能用的选项动作 |
|---|---|---|
| ⚔ 战斗 combat | 一个敌人 | 动手（必有）、检定（如偷偷绕过）、付出（如贿赂） |
| 💬 遭遇 encounter | 会说话的人或生物 | 检定、付出、赌运、动手、接委托 |
| 🔍 发现 discovery | 废墟、宝箱、遗物 | 检定、赌运、付出 |
| ⚠ 险境 hazard | 断桥、风暴、落石 | 检定、付出（离开 = 绕路，多耗口粮） |
| ✨ 秘境 mystic | 祭坛、精灵、诅咒之物 | 检定、付出、赌运 |
| ⚖ 抉择 dilemma | 两难的道德选择 | 付出、检定、接委托、动手 |
| 📜 委托 quest | 之前接下的委托的结局 | 检定、付出、动手、赌运（收获更大，可给遗物） |
| 🛒 交易 trade | 行商（带铁砧） | 打开商店：补给、卖铁料、强化 |
| 🔥 休憩 rest | 安全的歇脚地 | 免费扎营，完全恢复 |

**选项动作**
- **检定**：属性 + 难度（易 / 中 / 难 → DC），d20 + 调整值 + 熟练加值。难度越高收获越大。
- **付出**：花金币、口粮、药水、生命、铁料或魔晶，换一份确定的大收获。
- **赌运**：五五开，收获大、风险也大。
- **动手**：进入战斗（攻击 / 喝药水 / 逃跑）。
- **接委托**：4~8 里后会遇到委托的结局事件。同时只能接一个。
- 每张卡都可以**离开**，有时也可以先**喝药水**再做决定。

- 选完之后，日志里会出现 AI 预先写好的**结果旁白**（成功一句、失败一句，带 ✦）。

**收获菜单**：金币、口粮、药水、恢复生命、铁料、魔晶、经验、祝福、遗物（只有困难检定和委托结局才给）、侦察。
**风险菜单**：受伤、丢金币、丢口粮、诅咒、中毒、被袭击（转入战斗，敌人先手）、迷路、疲惫。

数值由规则按威胁等级和难度计算（`scripts/road.js` 里的 `rewardAmount` / `riskAmount` / `costAmount`），AI 只能从菜单里挑类型。

**岔路口**：每 5 里选一次接下来走哪条路（守关者不会被跳过）：

| 路 | 效果 |
|---|---|
| 大路 | 威胁 -1，行商和歇脚地更多，路边采不到东西 |
| 荒野 | 威胁 +1，发现和秘境更多，收获 ×1.3，采集 +15% |
| 捷径 | 每步走 2 里（只吃 1 份口粮），威胁 +2，疲劳 +2，没有行商和歇脚地 |

**疲劳**：每走一里 +1（捷径 +2），扎营清零。6 起 d20 -1，9 起 -2，12 起 -3 并且每里掉 1d4 生命。

**状态效果**：祝福（d20 +2）、诅咒（d20 -2）、中毒（每里 -1d4，喝药水可解）、疲惫（AC -2，扎营解除）、侦察（接下来更容易避开战斗）。

## 二、资源与强化

| 资源 | 用途 | 来源 |
|---|---|---|
| 口粮 | 每里 1 份，开局只有 5 份，吃完会挨饿掉血；扎营也要 1 份 | 行商（价格随里程上涨）、战胜野兽、事件、采集（只有平原和森林，12%；荒野更容易，大路不行） |
| 治疗药水 | 回血、解毒 | 行商、事件、守关者 |
| 金币 | 买补给、强化、付出代价 | 战斗、事件 |
| 铁料 | 强化材料；也可以卖钱 | 战斗、发现、事件 |
| 魔晶 | 高级强化材料 | 秘境、守关者、高收获事件 |

**携带上限**：口粮 8 + 4×背包等级，药水 3 + 背包等级；装不下的会丢掉。

**强化**（在交易事件里，用金币 + 铁料，高级还要魔晶）：

| 强化 | 最高 | 效果 |
|---|---|---|
| 武器 | +5 | 命中与伤害 +1 / 级 |
| 护甲 | +5 | AC +1 / 级 |
| 背包 | Lv3 | 口粮上限 +4、药水上限 +1 / 级 |
| 营具 | Lv3 | 扎营回血 50% → 65% → 80% → 100%，夜袭 20% → 14% → 8% → 4% |

**遗物**（最多 3 件，满了会化成 2 魔晶）：幸运符（d20 +1）、吸血之刃（命中回 2 血）、旅人靴（25% 不耗口粮）、守护护符（AC +1）、猎人号角（击败敌人金币 ×1.5）、炼金瓶（药水 ×1.5）、星图（预知下一里的事件类别）、不灭余烬（致命伤时留 1 血，用掉）。

## 三、职业、战斗与天赋（简化 D&D 5e）

开局先掷 6 个属性值（4d6 去掉最低），再选职业，属性按职业的主次自动分配（主属性拿最高值）。

| 职业 | 生命骰 / 开局 | 攻击 | 资源 | 技能 |
|---|---|---|---|---|
| 战士 | d10 / 14 + 体质 | 长剑 1d10 + 力量；5 级起每回合两次 | **怒气** 6：命中 +1、挨打 +1、防御 +1，每场清零 | 盾击 2（命中眩晕 1 回合，打断蓄力）· 顺劈 3（必中 2 骰）· 战吼 4（回 25% 生命 + 格挡） |
| 游荡者 | d8 / 13 + 体质 | 细剑 1d8 + 敏捷；每场第一击偷袭 | **连击** 5：命中 +1（暴击 +2），每场清零 | 闪避 1（躲开下一击）· 淬毒之刃 2（中毒 3 回合）· 剔骨（花光连击，每点 1d6+1） |
| 法师 | d6 / 12 + 体质，AC 13 起 | 火焰箭 1d10 + 智力；第一发魔法飞弹必中 | **法力** 6：**不会自己恢复**，只有扎营补满 | 护盾术 1（格挡）· 冰霜射线 2（必中 + 冻结）· 火球术 3（必中 3d6+） |
| 牧师 | d8 / 13 + 体质 | 钉头锤 1d8 + 感知；对亡灵 +1d8 | **信仰** 6：每回合 +1，每场至少 2 | 治疗术 2 · 惩戒 2（+2d8，亡灵 4d8）· 庇护所 3（大量格挡 + 解毒） |

**战斗**（每回合：你行动 → 敌人按预告行动）：
- 敌人每回合**预告下一步**：攻击（显示伤害范围）、连击、重击（先蓄力一回合）、防御（格挡）、毒咬、吸血、扒窃金币、诅咒。
- 你的选择：**攻击**、**防御**（格挡 3 + 熟练 + 护甲强化，挡到你下次行动）、**技能**、喝药水、逃跑。眩晕 / 冻结能让敌人跳过一回合，也会打断蓄力。
- **敌人特性**决定它爱出什么招：重甲（AC +2、常防御）、迅捷（常连击）、剧毒、蛮力（常蓄力重击）、再生、奥术（吸血、诅咒）、亡灵（免疫毒、怕圣光）、盗贼（偷钱）。AI 写卡时挑特性，没挑就按精灵默认。
- 攻击和检定：d20 + 调整值 + 熟练加值，对抗 AC / DC；20 暴击、1 自动失败。

**升级**：生命 + 职业生命骰 + 体质；4、8、12…级主属性 +2；偶数级资源上限 +1；每级**三选一天赋**：坚韧、铁壁、拾荒者、老兵、觅食者、吃苦耐劳、致命、砍价高手，以及每个职业两个专属天赋（狂怒、还击、剧毒专精、奥术涌流、塑能、虔诚）。

- 扎营：每里一次，消耗 1 份口粮，回血、清除疲劳、法师补满法力；地区每 10 里变换；威胁随里程增长，后期越来越快。
- 最远纪录保存在本机，不随读档回滚。

## 四、AI 与画面模块

**AI 在这里做什么**（界面里 AI 写的内容都带 ✦）：
- 把每个掷出的事件写成事件卡：标题、描述、2~3 个有取舍的选项（会根据你缺什么、累不累、血多少来出难题）。
- 给每个选项预先写好**成功 / 失败的旁白**，你做出选择后才揭晓。
- 给敌人挑**特性**（直接改变它在战斗中出什么招）、写开打时的**台词**和被打败时的描写。
- 写一条贯穿整段旅程的**旅途主线**（显示在顶部横幅下），每张卡都会读到上一次的主线并往前推进一点——被跟踪、预言、诅咒的遗物……每局都不一样。

AI 只有 0 级权限：不能改任何数值。它写的每个字段都会被规则校验（动作是否适用于这个类别、收获是否允许、精灵是否在白名单里），不合规的会被丢掉或换成默认值；如果一个可用的选项都没剩下，规则会补一组通用选项。AI 超过 25 秒没有回应时，事件卡会提示检查 AI 设置，并显示“重试”按钮。

画面以 256×144 的像素网格为基准（组件 `ui/game.js` 按窗口整数倍放大绘制），每一帧由模块叠出来：

| 层 | 模块 | 谁来选 |
|---|---|---|
| 背景 | 6 个地区 × 4 层（天空、远景、中景、地面与路），视差卷动 | 规则 |
| 主体 | 敌人 `wolf` `spider` `bandit` `skeleton` `troll` `drake` `ooze` `wisp` `warden`；场景 `chasm` `rocks` `thorns` `chest` `cart` `shrine` `campfire` `stranger` | AI（按类别限定白名单） |
| 染色 | `none` `red` `green` `blue` `gold` `shadow` `pale` `purple` | AI |
| 时间 / 天气 | `day` `dusk` `night` / `clear` `rain` `snow` `fog` `embers` `fireflies` `leaves` | AI（有默认值） |
| 主角 | 站立、走路 4 帧、攻击 | 规则 |

**提前生成**：AI 始终比玩家多准备一里。开局就掷出第 1 里的事件并在后台请求 AI（`trigger: script` + `api.ai.request`，不阻塞游戏），之后每走一里就接手已经写好的卡片、同时开始准备下一里。玩家处理眼前的事时，下一里已经在写了，走过去时卡片直接出现；事件面板上会显示“✓ 下一里已经备好”。如果还没写好，就先显示“前方有动静”，写好后自动出现；请求失败或读档后丢失，会自动重新请求。下一里的地区、守关者、委托回访在掷骰时就已确定，所以提前写的内容和实际情况一致。

**界面**：故事接管整个窗口（`ui.takeover`），整个游戏画面是一个**自定义组件**（`ui/game.html` + `game.js` + `game.css`）：

- 组件里自己画像素场景（背景 4 层视差、精灵、天气粒子、时间色调），按窗口高度整数倍放大，像素不糊；界面用 HTML 叠在场景上，文字是原生分辨率。
- 左上：头像框、生命条（受伤时有残影）、经验条、资源；顶部中间：地区和里程；右侧：从侧面滑入的羊皮纸事件卡（选项带图标和彩色标签）；底部中间：行动按钮；左下：半透明的冒险日志（点开查看全部）；右下：角色 / 行囊 / 遗物 / 旅程 / 日志。
- 开局是标题画面，四个职业卡上的主角在踏步；战斗时伤害数字飘在角色头上；倒下时有结局面板和 AI 写的结语。
- 战斗时右侧是战斗卡（敌人特性、格挡、中毒、眩晕，以及醒目的“下一步”预告），底部是攻击 / 防御 / 三个技能（标出资源消耗）/ 药水 / 逃跑；左上头像旁有职业资源条和疲劳值。
- 键盘：空格 = 继续前进 / 攻击，D 防御，战斗中 1–3 放技能，其他时候 1–9 选选项，Q 药水，C 扎营，F 逃跑，Esc 关闭弹窗。
- 竖屏（手机）时画面在上、界面在下。
- 像素边框、按钮、图标都由 `tools/art/endless-road/` 生成。

规则把要显示的内容写进玩家可见的状态（`ui_card`、`class_info`、`journal`、`scene_fx` 等），组件只负责显示；按钮调用 `pick_class` / `walk` / `camp` / `potion` / `attack` / `defend` / `skill` / `flee` / `choose` / `trade` / `pick_perk` / `go` 动作。`scripts/scene.js` 只推进动画计时（`realtime.on_tick`）。这个故事需要打开客户端设置里的“自定义组件”。AI 生图暂时去掉了（当前客户端还没有实现生图）。

**平台**：电脑和手机都支持（接管窗口后，客户端不会把布局压成单列）。

素材的源文件和加新精灵的方法见仓库 `tools/art/endless-road/`。

## 文件

```
story.yaml          主文件（状态、动作、AI 接入点、界面）
scripts/road.js     规则：事件框架、选项结算、资源与强化、遗物、状态效果、战斗（意图、特性、技能）、天赋、岔路、疲劳、界面数据
scripts/scene.js    动画计时（卷动、受击、攻击、飘字）
ui/game.*           整个游戏画面（自定义组件）：场景渲染 + 游戏界面；ui/*.png 是像素边框、按钮、图标、职业头像
assets/bg/          背景分层；assets/sprites/ 精灵；assets/cover.png 封面
```
