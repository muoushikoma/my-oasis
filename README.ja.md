# マイ・オアシス（我的绿洲）

非営利のオープンソースプロジェクトです。AI が紡ぐ冒険物語のプラットフォームで、**ルールはすべて物語の作者が決めます**。何を固定にし、何を AI に任せるか、各 AI 部分の役割・裁量・守るべきルールも作者が決め、プレイヤーは物語のルールを超えられません。

- 🌐 物語サイト：<https://muoushikoma.github.io/my-oasis/>
- ⬇️ クライアント（Windows / Android）：[Releases](https://github.com/muoushikoma/my-oasis/releases/latest)

このリポジトリには**クライアントのソースコード**と**公開物語ライブラリ**（`stories/`）の両方があります。

## 遊び方
1. クライアントをインストールし、ウィザードで自分の AI を接続します（ルールのみの物語は AI 不要）。
2. 「プレイ → オンラインライブラリ」で、**ログインなしで**閲覧・ダウンロード・プレイできます。物語一覧 `index.json` はマージ後に自動生成され、固定 Release `story-index` に添付されます（リポジトリには保存しません）。

## 投稿
- **アプリから（推奨）：** 「創作 → 投稿」で GitHub にログインし、物語を選ぶと、検証・fork・ブランチ作成・PR 提出まで自動で行います。
- **Web から：** fork して `stories/<id>/` に置き、`main` へ PR を出します。

fork からの PR は **`stories/` 以外を変更できません**。メンテナーの審査・マージ後に一覧とサイトが自動更新されます。性的コンテンツは受け付けません（`all-ages` / `teen` のみ）。
