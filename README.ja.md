# My Oasis（社内向け）

> **非公開・クローズドソースのプロジェクトです。社内利用限定、外部への共有は禁止です。**

My Oasis は AI が進行するアドベンチャーストーリーのプラットフォームです。プレイヤーは**デスクトップクライアント**で物語をダウンロードして遊び、クリエイターはクライアント外でストーリーパッケージを作り、クライアントでインポート・テスト・アップロードします。

## 構成
- **デスクトップクライアント**（Tauri 2、まず Windows 版）：ローカルのルールエンジン、作者が定義する AI 接続点（1 つの物語につき 1 つの AI モデル）、ストーリーのインポート・検証（わかりやすいエラー表示）・テストプレイ・アップロード。**エディタは内蔵しません**。作者はクライアント外でストーリーパッケージを作成します（手書き、または [AI 作成ガイド](docs/ai-authoring-guide.md) をチャット AI に渡して生成）。画面構成は作者が定義し、未定義ならシンプルなテンプレートを使います。
- **サーバー**（自前運用、Alibaba Cloud ECS・中国本土リージョン）：アカウント、物語のアップロード／審査／ダウンロード、ユーザーデータ（作品、ダウンロード履歴、セーブのクラウド同期）。
- **AI は持ち込み**：プレイヤー自身の API キーまたはローカルモデルを使用。キーは OS のキーチェーンにのみ保存され、サーバーへは一切送信しません。

## 設計のポイント
- ルール・画面構成・AI を使う箇所はすべて作者が定義します。プラットフォームに固定のゲームシステムはなく（ダイス等は任意のテンプレート）、エンジンがルールを強制し、各 AI 接続点は作者が与えた権限の範囲でのみ動作します。
- サーバーアドレスはハードコードせず、署名付きでリモート更新可能なブートストラップ設定から取得します。
- IP のみのテスト段階では自己署名証明書＋クライアント側の公開鍵ピンニングを使用。パスワードは平文で送信せず、サーバー側で argon2id により保存します。
- 中国本土の規制（実名登録、ICP 届出、コンテンツ審査）に従い、成人向けコンテンツは受け付けません。

## ステータス
M1（エンジン・検証器・CLI）完了、M2（スタンドアロン Windows クライアント）進行中。サーバー機能は**一時停止**し、まずスタンドアロン版で反応を見ます。

## 開発
```bash
pnpm install
pnpm test
pnpm oasis validate examples/lighthouse-mini
pnpm oasis play examples/guess-the-box
# AI 接続：環境変数 OASIS_API_KEY、OASIS_BASE_URL、OASIS_MODEL
```
API キーは絶対にコミットしないでください（環境変数からのみ読み込みます）。
