# Privacy policy / 隐私政策

**English** · [中文](#中文)

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

- **No telemetry.** My Oasis has no analytics, tracking, crash reporting or advertising. The project runs no server.
- **AI provider (chosen by you).** When you play with AI, your story text and inputs are sent to the AI provider *you* configure, using *your* API key. That provider's privacy policy applies. Your API key is stored in your operating system's secure credential store and is only sent to that provider.
- **GitHub (when you use it).** Browsing and downloading stories fetches public files from GitHub / jsDelivr. Submitting a story, if you choose to, signs in to GitHub and opens a pull request under your account. [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) applies.
- **Local data.** Saves, settings and token-usage records stay on your device. Stories run in a sandbox and cannot access the network, your files or your clipboard contents.

## 中文

除非用户本人要求，本程序不会把任何信息发送到其他网络系统。

- **不收集数据**：没有统计、追踪、崩溃上报或广告，项目也没有服务器。
- **AI 服务（你自己选）**：用 AI 玩故事时，故事文字和你的输入会发给**你自己设置的** AI 服务商，用**你自己的** API Key，适用该服务商的隐私政策。API Key 存在系统的安全凭据库里，只发给该服务商。
- **GitHub（你用到时）**：浏览和下载故事时会从 GitHub / jsDelivr 下载公开文件；你选择投稿时，会登录 GitHub 并用你的账号开合并请求。适用 GitHub 的隐私声明。
- **本地数据**：存档、设置和 token 用量记录都只留在你的设备上。故事在沙盒里运行，不能联网，不能读你的文件和剪贴板。
