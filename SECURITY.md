# 安全策略 / Security Policy

## 简体中文
**请不要用公开 Issue 报告安全漏洞。**
请使用 GitHub 私密漏洞报告：打开本仓库的 **Security → Report a vulnerability**（https://github.com/muoushikoma/my-oasis/security/advisories/new ）。

特别关注的问题：故事脚本逃出 QuickJS 沙箱、绕过 CSP、读取或泄露 API Key、联网/读剪贴板/访问文件、遮挡退出出口、绕过 AI 权限检查、伪造客户端界面。

请写明受影响版本、平台、复现步骤（可附最小故事包）。维护者会尽快回复，修复前请不要公开细节。只支持最新版本。

## English
**Please do not report vulnerabilities in public issues.**
Use GitHub private vulnerability reporting: **Security → Report a vulnerability** (https://github.com/muoushikoma/my-oasis/security/advisories/new).

Of particular interest: sandbox escapes from QuickJS, CSP bypasses, reading or leaking API keys, network/clipboard/file access from scripts, covering the exits, bypassing AI permission checks, and spoofing client UI.

Include the affected version, platform and reproduction steps (a minimal story package helps). We'll respond as soon as we can; please keep details private until a fix ships. Only the latest release is supported.
